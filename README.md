# 🎨 ART SHOW CASE - Divisi Seni Rupa Polibatam

Portal Web Resmi Pameran Seni **Art Showcase** dengan tema *"History"* oleh Divisi Seni Rupa Politeknik Negeri Batam.
https://student-organization-seni-rupa-2.vercel.app/#home 

---

## 🚀 Tech Stack
- **Frontend**: React (Vite) + Tailwind CSS (Retro Memphis & Neo-Brutalism Theme) + Lucide Icons + Framer Motion
- **Backend**: Laravel 11 (REST API, Client IP Logging, Laravel Sanctum)
- **Database & Storage**: Supabase (PostgreSQL + Supabase Storage Bucket for Artwork Media)

---

## 📋 Fitur Utama
1. **Presensi Digital & Deteksi IP**: Pencatatan kehadiran pengunjung & panitia (Nama, NIM/Identitas, Kategori, IP Address, Device Info, Waktu).
2. **Katalog Karya Interaktif**: Pameran karya seni anggota (Lukis, Kerajinan, Sketsa), deskripsi filosofis, medium bahan, modal zoom, serta sistem like/apresiasi.
3. **Denah Layout Interaktif (Student Centre Lt. 3)**: Peta zona pameran (Booth Lukisan, Kerajinan, Pojok Live Painting, Panggung Utama).
4. **Live Rundown Acara**: Timeline kegiatan dengan status *Live Now*, *Upcoming*, dan *Completed*.
5. **Digital Guestbook**: Pojok kesan dan pesan interaktif bagi pengunjung dan Maba.
6. **Dashboard Panitia**: Manajemen karya, controller status rundown, monitoring log IP absensi, dan ekspor data kehadiran.
